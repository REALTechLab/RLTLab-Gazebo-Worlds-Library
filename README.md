## 🛠️ Install
#### 1. Clone project
```bash
git clone https://github.com/REALTechLab/RLTLab-Gazebo-Worlds-Library.git
```

#### 2. Run the world
```bash
cd RLTLab-Gazebo-Worlds-Library
cd worlds
cd 55000-***** <***** is name of district>
gz sim 55000-*****.world 
```
